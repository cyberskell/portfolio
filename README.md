# cyberskell.com — Ethan Haskell's Portfolio

A personal portfolio site built with plain HTML, CSS, and JavaScript — no
frameworks, no build step. Live at **[cyberskell.com](https://cyberskell.com)**.

## What's on the site

| Section | What it shows |
|---|---|
| **Home** | Intro, current status, links to the resume, GitHub, and contact |
| **About** | Skills grouped by category, education, certifications, and a timeline of work/leadership experience |
| **Projects** | Three infrastructure projects (home lab, self-hosted web server, Raspberry Pi cluster) with GitHub links |
| **Resume** | Download/view the resume as a PDF, plus a QR code back to this site |
| **Contact** | A form and direct links (email, LinkedIn, GitHub) |

There's also a floating **chat assistant** (bottom-right) that answers
common questions about my background.

## How the chatbot works

It's a small rule-based FAQ bot in plain JavaScript — no external API, no
cost, no network request required, so it works instantly on GitHub Pages.

- `js/chatbot-data.js` holds a list of **intents**: an id, a set of trigger
  keywords/phrases, an optional weight, and a canned response.
- `js/script.js` takes whatever the visitor types, lowercases and strips
  punctuation, and scores it against every intent's keyword list (a small
  bag-of-words matcher — phrase keywords score higher than single-word
  matches, and a per-intent `weight` lets stronger signal words outrank
  generic ones). The highest-scoring intent above zero wins; ties and
  no-matches fall back to a "try asking about..." message.
- To make the bot smarter, you don't touch the matching logic at all —
  just add a new `{ id, keywords, response }` object to `CHATBOT_INTENTS`
  in `chatbot-data.js`.

This is intentionally simple (a keyword scorer, not a trained NLP model),
which keeps it free to run and easy to extend. If you want true NLP later,
the natural upgrade path is swapping `matchIntent()` for a call to a
hosted model (e.g. the Anthropic API) — the rest of the chat UI doesn't
need to change.

## Deployment: GitHub Pages + a Squarespace-registered domain

This repo is set up to deploy for free on **GitHub Pages** and serve on
`cyberskell.com`, which stays registered with Squarespace — you're only
using Squarespace for DNS, not for hosting.

**1. Push this repo to GitHub** as `cyberskell/portfolio` (or any repo
name — if it's not `cyberskell.github.io`, GitHub Pages will still work,
it just serves from a project URL until the custom domain is attached).

**2. Turn on GitHub Pages**
   - Repo → **Settings → Pages**
   - Source: **Deploy from a branch** → `main` → `/ (root)`
   - Save. GitHub will build a `https://cyberskell.github.io/portfolio/` URL.

**3. Point your domain at GitHub Pages**
   The `CNAME` file in this repo already contains `cyberskell.com`, which
   tells GitHub Pages which custom domain to expect. You still need to add
   DNS records on Squarespace's side:

   - Log into Squarespace → **Domains** → `cyberskell.com` → **DNS Settings**
   - Add these **A records** for the apex domain (`@`), pointing at GitHub's
     Pages IPs:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Add a **CNAME record** for `www` pointing to `cyberskell.github.io`
   - Back in GitHub repo → Settings → Pages → set the custom domain field to
     `cyberskell.com` and enable **Enforce HTTPS** once it's available
     (can take a few minutes to a few hours for DNS + the certificate).

**4. Verify** — visiting `https://cyberskell.com` should load this site
directly (no Squarespace page in between).

## Local development

No build tools needed. Either open `index.html` directly in a browser, or
serve it locally so relative paths behave exactly like production:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Regenerating the QR codes

`assets/img/qr-code-site.png` (styled, used on the website) and
`assets/img/qr-code-print.png` (plain black-on-white, embedded in the
resume PDF for reliable scanning) both point at `https://cyberskell.com`.
Regenerate them with:

```python
import qrcode
qrcode.make("https://cyberskell.com").save("assets/img/qr-code-print.png")
```

If you ever update the resume itself, edit
`assets/resume/Ethan_Haskell_Resume.pdf` directly in whatever tool you
used to make it (Word, Canva, etc.) — it's a plain static file in this
repo now, not generated by a script.

## Contact form

The form currently opens the visitor's email client with a pre-filled
message (`mailto:`) — zero backend, zero cost, works anywhere. If you'd
rather visitors submit without leaving the page, swap the submit handler
in `js/script.js` for a form service like
[Formspree](https://formspree.io/) or [EmailJS](https://www.emailjs.com/)
(both have free tiers and a few lines of JS).
